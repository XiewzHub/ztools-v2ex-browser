# V2EX 热门与最新帖子插件设计

## 目标

将现有 ZTools Vue 插件骨架改造成免 Token 的 V2EX 帖子浏览器。用户可在 ZTools 中查看热门或最新帖子，在当前窗口阅读单帖详情和回复，并跳转到浏览器打开原帖。

## 范围

- 提供一个 `v2ex` 功能入口，支持 `v2ex`、`V2EX 热门`、`V2EX 最新` 指令。
- 默认加载热门帖子；从“最新”指令进入时默认加载最新帖子。
- 支持热门与最新列表切换、手动刷新和对当前已加载帖子的本地关键词过滤。
- 展示帖子标题、节点、作者、回复数和相对发布时间。
- 支持查看帖子正文、作者和节点信息，以及回复列表。
- 支持在系统浏览器打开原帖。

## 非目标

- 不提供登录、Token、发帖、回复、收藏或通知能力。
- 不实现服务端代理、持久化缓存或跨设备同步。
- 不对 V2EX 列表做服务端搜索；搜索仅过滤已加载的数据。

## 插件配置

`src-ztools/plugin.json` 将只保留一个 `v2ex` 功能，标题为 V2EX 帖子浏览，使用以下命令：

- `v2ex`
- `V2EX 热门`
- `V2EX 最新`

进入参数中的触发指令用于决定首次加载的列表类型；没有匹配到“最新”时加载热门。

## 数据与请求

页面直接从渲染进程请求以下无需 Token 的 V2EX API：

- `https://www.v2ex.com/api/topics/hot.json`
- `https://www.v2ex.com/api/topics/latest.json`
- `https://www.v2ex.com/api/topics/show.json?id=<id>`
- `https://www.v2ex.com/api/replies/show.json?topic_id=<id>`

将请求、状态转换、数据标准化和展示辅助函数放在独立 TypeScript 模块中，Vue 组件只负责协调交互和渲染。帖子详情与回复采用并发请求，分别维护加载和失败状态，因此其中一个失败时不影响另一个内容区。

## 界面与状态

应用有两个视图：列表和详情。

列表视图顶部包含热门/最新切换、搜索输入框和刷新按钮。默认显示加载状态，加载成功后渲染可滚动的帖子列表；筛选无匹配时显示空状态。请求失败时显示错误信息及重试按钮。

详情视图顶部包含返回、刷新和在浏览器打开原帖按钮。正文区域展示标题、节点、作者、创建时间、正文 HTML 和回复数；回复区域按时间顺序展示每条回复的作者、时间和内容。正文与回复 HTML 以受控方式渲染，外部链接在新窗口打开。

所有请求状态都由触发的列表类型或帖子 ID 绑定，迟到的旧请求不能覆盖后一次操作的结果。

## 错误处理

- HTTP 非成功状态和网络异常统一转换成面向用户的中文错误提示。
- 刷新失败时保留上一次成功显示的内容。
- 空响应与无回复属于正常状态，展示相应空状态而非错误。
- 找不到帖子详情时显示详情不可用，并保留返回列表的路径。

## 验证

- 为纯函数和请求层添加自动化测试：指令到默认列表类型的映射、关键词过滤、时间格式化、HTTP 失败转换和并发详情结果处理。
- 在浏览器中启动 Vite 开发服务器，确认热门与最新列表可切换、筛选可用、详情与回复可加载、外链按钮可触发。
- 运行 TypeScript 检查与生产构建，确认产物输出至 `src-ztools/dist/`。

## 验收标准

1. 在 ZTools 输入 `v2ex` 可查看热门帖子，在输入 `V2EX 最新` 时首次打开最新帖子。
2. 热门与最新可切换并可手动刷新。
3. 搜索框能对当前列表的标题、节点和作者进行过滤。
4. 点击帖子可查看详情和回复；详情和回复各自失败时有明确提示且不阻塞另一区域。
5. 可从详情跳转至 V2EX 原帖。
6. 项目通过测试、类型检查和生产构建。
